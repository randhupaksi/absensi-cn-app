# Absensi CN App

Frontend application untuk project `Absensi CN`.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui
- TanStack Query
- TanStack Table
- React Hook Form
- Zod

## Menjalankan App

```bash
npm install
npm run dev
```

## Script

```bash
npm run dev
npm run lint
npm run typecheck
npm run build
```
